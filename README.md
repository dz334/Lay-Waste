# Lay Waste
A Spite-Powered 2D Horde-Commander Souls-like

You are a powerful duck summoner whose flock has been repossessed by a corrupt Fox Syndicate. Armed with nothing but spite and a handful of eggs, it’s time to reclaim your flock and lay waste to the fox provinces.

## How to Run
This game is built using the LÖVE (Love2D) framework. To run the game from source, follow these steps:

1. Install LÖVE
Download and install the version of LÖVE compatible with your OS Windows/macOS/Linux [Download here](https://love2d.org/):

2. Clone the Repository
Open your terminal or command prompt and run:

git clone https://github.com/dz334/Lay-Waste
cd lay-waste

3. Launch the Game

You can run the game by either dragging the project folder onto the love executable, or via the command line:

Windows:
Bash "C:\Program Files\LOVE\love.exe" .

macOS:
Bash open -a love .

Linux:
Bash love .
